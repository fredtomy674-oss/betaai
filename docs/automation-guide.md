# دليل أتمتة الوكلاء

## استقبال المهمة
يتلقى الوكيل الطلب عبر واجهة المنصة أو تذكرة GitHub ويقوم بتحليله.

## خطوات التنفيذ
1. قراءة المتطلبات بدقة وتحديد الأدوات اللازمة.
2. تنفيذ الكود أو السكربت واختباره محلياً للتأكد من خلوه من الأخطاء.
3. حفظ الملفات الناتجة بالمسارات المحددة.

## مراجعة Pull Request
يتم فحص التغييرات والتأكد من مطابقتها للمعايير قبل الاعتماد.
